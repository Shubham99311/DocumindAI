🚀 DocuMind AI

DocuMind AI is a powerful AI-driven document analysis system designed to automate the extraction, classification, and summarization of various document types such as invoices, resumes, and reports.

The system leverages OCR, machine learning, and NLP techniques to transform unstructured documents into meaningful insights through an easy-to-use web interface.

🔄 Workflow ::: 
Upload Image/PDF >> 
Extract text using OCR >> 
Clean and preprocess text >> 
Convert text to features using TF-IDF >> 
Classify document using XGBoost >> 
Generate summary using DistilBART >> 
Display results on Streamlit UI >>
